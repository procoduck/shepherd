Docs/Fleet/Connect a collector

Connect a collector

Add a remotecfg block to the collector's config.alloy. Shepherd resolves the collector by its cluster and role attributes — role is one of metrics, logs, singleton, or receiver.

config.alloy
remotecfg {
  url = "http://shepherd:8080"
  basic_auth {
    username = "<token-uuid>"
    password = "<token-secret>"
  }
  attributes = {
    cluster = "<cluster-name>",
    role    = "metrics",
  }
  poll_frequency = "60s"
}

On first poll, an unclaimed cluster gets served an empty config so it keeps running whatever it already has locally — nothing is disrupted until an app admin claims the cluster for an organisation (Roles) and one of that organisation's admins enables pipelines that match it.

With Grafana's k8s-monitoring chart

If your clusters run Grafana's k8s-monitoring Helm chart, Shepherd writes the values for you. On Collectors, an organisation admin chooses Connect a cluster, names the cluster and picks its collectors (metrics, logs, singleton, receiver). Shepherd returns:

  • shepherd-layer.yaml — each collector's remoteConfig, pointed at this Shepherd's server.base_url, with the cluster name and role as attributes and the organisation's tenant if it has one;
  • shepherd-credentials.yaml — loads the agent token into each collector from a Kubernetes Secret (it names the Secret; it never contains the token);
  • the kubectl create secret and helm upgrade --install commands that use them.

Apply both files next to your own values — they set nothing else, so sizing, features and destinations stay yours. The values are checked against the k8s-monitoring version they name, and Shepherd's test suite installs that exact chart with them and watches a collector register and load a pipeline.

Two things still need an app admin: an agent token (Admin → Agent Tokens) for the Secret, and, once the collectors have registered, claiming the cluster for your organisation (Admin → Clusters). The dialog says which of those the cluster still needs. A cluster name another organisation already owns is refused.
