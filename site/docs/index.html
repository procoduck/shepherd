Shepherd documentation

Shepherd runs in your Kubernetes cluster and serves centralised pipeline configuration to a fleet of Grafana Alloy collectors over remotecfg. These pages cover installing it, connecting collectors, authoring pipelines, and deciding who may change what.

New here? Start with the Quickstart — install the chart, point a collector at it, and serve that collector a pipeline.
