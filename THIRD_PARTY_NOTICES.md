the one `web/pnpm-lock.yaml` resolves.

## elkjs

The Eclipse Layout Kernel compiled to JavaScript. The read-only graph view
(`web/src/visual/elkLayout.ts`) uses it to lay out a pipeline's graph.

- **Package:** `elkjs` (npm)
- **Version:** 0.12.0
- **Copyright:** Copyright (c) 2017 Kiel University and others.
- **Licence:** EPL-2.0 OR GPL-3.0-or-later. Shepherd distributes it under the **Eclipse Public
  License 2.0**: <https://www.eclipse.org/legal/epl-2.0/>. The full text also ships in the
  npm package as `LICENSE.md`.
- **Source code:** <https://github.com/kieler/elkjs/tree/0.12.0> (tag `0.12.0`, commit
  `ff5771d7165445c42c408bb8a090c8035272218c`). This is the source of the files below, as
  EPL-2.0 §3.2 requires. The layout algorithms themselves come from the Eclipse Layout Kernel,
  <https://github.com/eclipse-elk/elk>.
- **Files shipped:** `lib/elk-worker.min.js` (the layout engine, run as a Web Worker) and
  `lib/elk-api.js` (its client). Both are **unmodified**. They are bundled into the web UI that
  is embedded in the `shepherd` binary, as `assets/elk-worker.min-<hash>.js` and
  `assets/elk-api-<hash>.js`.
